# Security Policy

## Supported Versions

Only the latest release on `main` receives security fixes.

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Report them privately via [GitHub's private vulnerability reporting](https://github.com/teragonia/ChaosGraphQA/security/advisories/new). You'll need to be signed in to GitHub.

Include:
- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof-of-concept
- Affected versions if known

We'll acknowledge the report within 72 hours and aim to release a fix within 14 days for confirmed issues. We'll coordinate a disclosure date with you before publishing anything publicly.
